# D&D Assistant Server

Backend-сервер для приложения-помощника по Dungeons & Dragons (D&D). Этот проект представляет собой RESTful API, разработанный на C# и ASP.NET Core, который управляет данными игроков, персонажей, кампаний, миров и правилами игры.

## Основные возможности

* **Аутентификация и безопасность:** Регистрация, авторизация и управление сессиями пользователей с использованием JWT-токенов (`JWTService.cs`, `RefreshTokens`).
* **Управление игрой:**
    * **Кампании и миры:** Создание и ведение миров, кампаний и локаций (`WorldsController.cs`, `CampaignsController.cs`, `LocationsXY`).
    * **Персонажи:** Детальное создание персонажей, управление их классами, расами, характеристиками, инвентарем и известными заклинаниями (`CharactersController.cs`, `CharacterEngine`).
    * **События и сессии:** Отслеживание игровых сессий (`Session.cs`) и мировых событий (`WorldEvent.cs`).
    * **NPC:** Управление неигровыми персонажами (`NPC.cs`).
* **Игровая база данных (Справочник):** Централизованный доступ к заклинаниям, предметам, правилам и опциям создания персонажей (`SpellsController.cs`, `ItemsController.cs`, `RulesController.cs`).
* **Файловая система:** Загрузка и хранение пользовательских изображений (портреты персонажей, аватары, карты локаций) через `ImagesController.cs` (файлы сохраняются в `wwwroot/uploads`).

## Стек технологий

* **Язык:** C#
* **Фреймворк:** .NET (ASP.NET Core Web API)
* **ORM:** Entity Framework Core (Code-First)
* **Безопасность:** JSON Web Tokens (JWT)

## Требования

* Установленный [.NET SDK](https://dotnet.microsoft.com/download)
* Сервер базы данных (согласно провайдеру, настроенному в Entity Framework, например PostgreSQL, SQL Server или SQLite)
* Глобальный инструмент Entity Framework Core (`dotnet tool install --global dotnet-ef`)

## Установка и запуск

1.  **Клонируйте репозиторий:**
    ```bash
    git clone <url-репозитория>
    cd dnd-assistant-server
    ```

2.  **Настройте конфигурацию:**
    Откройте файл `appsettings.json` (или создайте `appsettings.Development.json`). Настройте строку подключения к вашей базе данных в секции `ConnectionStrings` и задайте секретный ключ для генерации токенов авторизации в секции, отвечающей за JWT.

3.  **Инициализация базы данных:**
    Проект использует миграции Entity Framework. Для применения текущей схемы к вашей базе данных выполните:
    ```bash
    dotnet ef database update
    ```
    *Примечание: При запуске проект может автоматически заполнять справочные данные базы (классы, расы, правила) благодаря встроенному механизму сидирования (`Data/Seeding/DbSeeder.cs`).*

4.  **Запуск сервера:**
    ```bash
    dotnet run
    ```
    По умолчанию API будет доступно по адресам, указанным в файле `Properties/launchSettings.json`.

## Структура проекта

* `Controllers/` — REST API эндпоинты, обрабатывающие входящие HTTP-запросы.
* `Models/` — Доменные сущности (Персонажи, Классы, Заклинания, Пользователи, Миры и т.д.), отображаемые в таблицы БД.
* `DB/` — Контекст базы данных Entity Framework (`MyDbContext.cs`).
* `DTOs/` — Объекты передачи данных (Data Transfer Objects) для сериализации и валидации данных между клиентом и API (`AuthDTOs.cs`).
* `Migrations/` — История изменений схемы базы данных.
* `Data/Seeding/` — Логика для первоначального наполнения базы данных статичным игровым контентом.
* `Shared/` — Общие компоненты системы и перечисления (`Enums.cs`).
* `wwwroot/` — Корневая папка для веб-сервера, содержащая загруженные статические файлы и медиа.
